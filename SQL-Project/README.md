
#  Maven Movies SQL Analysis

## Project Overview
This project focuses on SQL fundamentals using the Maven Movies Database in MySQL Workbench.

The objective is to practice retrieving, filtering, sorting, and analyzing data using SQL queries.

## Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## Database
Maven Movies Database

## Skills Demonstrated
- Database setup and table exploration
- SELECT and FROM statements
- Selecting specific columns
- Filtering data using WHERE
- Using comparison operators
- Filtering with AND
- Sorting data using ORDER BY
- Combining multiple SQL conditions
- Basic data exploration

## Project Tasks
1. Database setup and table listing
2. Retrieve all records from a selected table
3. Retrieve selected columns
4. Filter records using WHERE
5. Apply multiple filtering conditions using AND
6. Sort numeric and text columns
7. Create a combined SQL query
8. Review and validate all queries

## Project Files
- `module-8-maven-movies-analysis.sql` – Contains all SQL queries completed for this assignment.

## Learning Outcome
Developed practical SQL skills for exploring relational databases, retrieving relevant information, filtering records, and organizing query results.
